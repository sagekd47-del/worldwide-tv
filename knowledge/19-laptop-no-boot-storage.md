# Laptop powers on but does not boot into the operating system

## Symptoms
Power lights or fan operate, but the laptop shows a logo loop, boot device error, or blank startup screen.

## Safe checks
- Record the exact on-screen message and any diagnostic LED/beep pattern.
- Disconnect USB drives, memory cards, docks, and external devices.
- Enter firmware setup only using the model's documented key and check whether the internal SSD/HDD is detected; do not change settings randomly.
- If the drive is detected, use the operating system's recovery tools and protect important data first.
- If the drive is not detected, or clicking noises occur, arrange hardware inspection and avoid repeated boot attempts.

## Cautions
Do not initialise, format, or reinstall onto a drive that may contain unbacked-up data.
