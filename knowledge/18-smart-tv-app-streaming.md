# Smart TV streaming app buffering or failing

## Symptoms
Streaming apps buffer, reduce quality, fail to load, or show network errors.

## Safe checks
- Test another streaming app and another device on the same network.
- Run the TV's built-in network test and compare Wi-Fi with Ethernet if available.
- Restart the router and TV; allow the router to reconnect fully.
- Check date/time settings and install TV firmware/app updates through official settings.
- Check whether the service itself reports an outage.
- If only one app fails, clear that app's cache/data if the TV provides the option, noting that sign-in may be required again.

## Cautions
Do not install unofficial firmware or sideload unknown TV apps to fix buffering.
