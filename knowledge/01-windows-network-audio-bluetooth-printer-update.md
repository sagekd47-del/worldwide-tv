# Windows troubleshooting: network, audio, Bluetooth, printer, updates

## Network and internet
- Confirm whether other devices can reach the internet on the same network.
- Check Wi-Fi is enabled, airplane mode is off, and the correct network is selected.
- Restart the router only after checking whether other people depend on the connection; note ISP outage indicators first.
- Record whether the failure affects one app, one website, DNS lookups, or all internet access. Avoid changing DNS/firewall settings without evidence.
- Microsoft Get Help includes a network and internet troubleshooter. Official guide: https://support.microsoft.com/en-us/support/get-help/windows-troubleshooters

## Audio
- Check output device selection, mute/volume, app-specific volume, and cable/Bluetooth connection.
- Disconnect/reconnect the audio device; test another known-good app or output device.
- Use Windows Get Help audio troubleshooter before reinstalling drivers.
- Official guide: https://support.microsoft.com/en-us/support/get-help/windows-troubleshooters

## Bluetooth
- Confirm the accessory is charged, in pairing mode, and not already connected to another host.
- Toggle Bluetooth off/on; remove and re-pair only after noting pairing details.
- Run the Windows Bluetooth troubleshooter. Official guide: https://support.microsoft.com/en-us/support/get-help/windows-troubleshooters

## Printer
- Check power, display error, paper path, ink/toner, connection, selected printer, and print queue.
- Test a printer self-test page if the model supports it. Do not assume a network issue if USB printing also fails.
- Use the official manufacturer guide for model-specific maintenance and driver packages.

## Windows Update
- Record the full update error code and Windows build.
- Run the Windows Update troubleshooter; restart and retry only after noting any pending work.
- Official guide: https://support.microsoft.com/en-us/windows/experience/windows-update-troubleshooter
