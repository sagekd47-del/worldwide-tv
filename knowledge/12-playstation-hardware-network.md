# PlayStation console hardware and network troubleshooting

## Evidence to collect
Exact console model/generation, full error code and text, system software version, game/app, indicator light behavior, recent update or power event, network type and whether other devices are online.

## Safe initial checks
1. Check official PlayStation service status before assuming a local console fault.
2. Check power cable/outlet, ventilation, external USB devices and controller charge/pairing.
3. For network faults, compare wired Ethernet and Wi-Fi if possible; record NAT and exact error code rather than changing router security settings blindly.
4. Use the model-specific official troubleshooting and error-code pages. Do not apply instructions for another console generation.
5. Do not open the power supply or console while connected to mains. Repeated shutdown, burning smell, sparks or overheating require stopping use and qualified service.
