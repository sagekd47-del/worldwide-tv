# Android phone and tablet troubleshooting

## Evidence to collect
Exact brand/model, Android version, security update date, app name/version, full error text, storage remaining, whether the fault affects one app or the whole device, and recent changes.

## Apps crashing or not opening
1. Restart the phone and check whether only one app is affected.
2. Check available storage and install app updates from the official app store.
3. Check Android system updates and app permissions relevant to the feature.
4. If clearing cache is available for that app, try cache only first. Clearing storage/data can erase local app data and sign-in state; warn first.
5. Reinstall only after confirming the user can recover the account and any locally stored data.

## Wi-Fi, Bluetooth and mobile connection
1. Check Airplane mode, radios, signal and whether another device/accessory works.
2. Restart the phone and the router/accessory where appropriate.
3. Forget/re-pair only when credentials and pairing access are available.
4. Network settings reset is a later step because saved Wi-Fi networks, Bluetooth pairings, VPN and mobile network settings may be removed.

## Battery, charging and heat
Check charger/cable compatibility, charging port condition, battery usage by app, signal strength and recent software changes. Stop charging and using the device if the battery is swollen, leaking, hissing, unusually hot or smells abnormal. Do not insert metal objects or liquids into the charging port.
