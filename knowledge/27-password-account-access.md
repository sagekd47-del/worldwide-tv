# Account sign-in and password recovery

## Symptoms
User cannot sign in, password rejected, verification code not received, or account locked.

## Safe checks
- Confirm the username/email and check for typing errors, keyboard layout, and Caps Lock.
- Use only the service's official password-reset page or app.
- Check spam/junk folders and confirm the recovery email/phone is still accessible.
- Check the service status page if sign-in fails for many users.
- If compromise is suspected, change the password from a trusted device, sign out other sessions, and enable multi-factor authentication.

## Cautions
Never ask a user to reveal a password, one-time code, recovery code, or full payment details. Support staff should not need the user's password.
