# Game console cannot connect or disconnects from network

## Symptoms
Console cannot sign in, multiplayer disconnects, downloads stop, or network test fails.

## Safe checks
- Run the console's built-in network test and record the exact error code.
- Test another device on the same router to check whether the internet connection itself works.
- Restart the router and console; use Ethernet temporarily to compare with Wi-Fi.
- Check the platform's official network service status.
- Confirm date/time and install system updates from the console's official update menu.

## Cautions
Do not change router security settings broadly or expose the console using DMZ as a first troubleshooting step. Keep account credentials and recovery codes private.
