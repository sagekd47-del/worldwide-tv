# Windows startup failure and blue screen

## Symptoms
Windows fails to start, repeatedly restarts, shows a stop code, or enters Automatic Repair.

## Safe checks
- Record the exact stop code and any file name shown; different codes indicate different fault paths.
- Disconnect newly attached USB storage, docks, printers, and other peripherals, then try starting again.
- If Windows opens, back up important files before further repair attempts.
- Use Windows Recovery Environment options such as Startup Repair before considering Reset or reinstall.
- If the issue began after a driver or update, use the recovery options to uninstall the recent update or roll back the driver when available.

## Cautions
Do not repeatedly interrupt disk operations. Do not format or reinstall before checking for backups. Repeated clicking, grinding, or SMART disk warnings require stopping unnecessary use and arranging data-safe inspection.

## Evidence
Microsoft Windows recovery and startup troubleshooting documentation should be checked for the installed Windows version.
